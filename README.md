# SQL Analyst Academy V8 Academy

A browser-based, hands-on SQL learning platform for Data Analysts and Senior Data Analysts.

## Included
- 34-lesson beginner → advanced SQL curriculum
- Live DuckDB SQL execution in the browser
- Commerce, healthcare/pharmacy, contact-center and streaming datasets
- Interactive challenges with result validation and XP
- Data Explorer with schema and relationships
- SQL concepts visualizations and analyst mental models
- Query history and daily practice streak
- Four multi-step analyst capstones
- Interview Mode with answer submission and scoring
- Mastery dashboard
- Graduation checklist and printable completion certificate
- Responsive dark UI

## Run locally

```bash
npm install
npm run dev
```

Open the local Next.js URL shown by the terminal.

## Notes
DuckDB-Wasm runs in the browser, so the sample datasets do not require a backend database. Progress is stored locally in the browser with `localStorage`.


## V8 learning experience
- Interactive dashboard launch cards and clickable progress stats
- Deep SQL concept lessons with mental-model visuals, examples, common mistakes, and mini checks
- Concept-to-practice workflow with blank challenge editors
- Expanded visual teaching for execution order, JOINs, GROUP BY, windows, KPIs, and join debugging
